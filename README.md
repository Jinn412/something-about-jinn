# Something About Jinn

An interactive pixel-art personal portfolio told through objects, memories, and exploration.

## About

Something About Jinn is an interactive pixel-art portfolio experience inspired by exploration-driven games.

Players discover Jinn's education, professional experience, interests, and future direction through objects and environmental storytelling.

## Tech

- React
- TypeScript
- Vite
- Cloudflare Workers
