# Jinn's Pixel Journey

请帮我制作一个中文互动式个人介绍网站的第一版 Prototype。

这个项目叫做：

Something About Jinn

它不是传统简历网站，而是一个以复古像素游戏为叙事方式的互动个人介绍。

我会上传一张视觉参考图。请将它作为整个网站的视觉方向参考，而不是直接作为背景图片使用。

整体视觉要求：

- 完整的 2D 复古像素游戏风格

- 不要现代网页风格

- 不要 glassmorphism

- 不要圆角卡片 UI

- 不要极简 SaaS 风格

- 所有 UI 都应该像一款复古像素 RPG 游戏

- 整体画面不要过于精美或 3D

- 像素颗粒应该清晰可见

- 页面应该让用户感觉自己正在进入一个小游戏，而不是浏览一个普通网页

网站目前只需要完成以下三个主要阶段：

==================================================

SCENE 1 — TITLE SCREEN

==================================================

页面背景是一片模糊、低信息量的像素天空。

颜色是偏蓝灰色。

可以有：

- 模糊的像素云

- 轻微的雾

- 非常轻微的雨感

不要使用纯黑背景。

屏幕中央有一个漂浮的复古木质像素框。

木框中显示：

Something About Jinn

文字使用像素游戏风格字体。

木框下方有一个较小的像素按钮：

▶ NEW GAME

点击 NEW GAME 后：

整个画面 Fade Out。

短暂停顿。

然后进入下一步。

==================================================

SCENE 2 — CHARACTER SETUP

==================================================

出现一个复古像素游戏风格的输入面板。

所有文字使用中文。

需要两个输入框：

你的名字：

[                    ]

你最喜爱的事物：

[                    ]

底部：

[ 确认 ]

不要设计成现代 Form。

它应该像复古游戏中的角色信息输入界面。

用户输入的信息需要保存到网站状态中。

暂时不需要数据库。

点击确认后：

Fade Out。

短暂停顿。

然后进入主场景。

==================================================

SCENE 3 — TRAVELING MERCHANT MAIN HUB

==================================================

这是整个网站最重要的场景。

场景发生在白天的雨天。

镜头不是传统游戏的俯视角。

用户是正面面对旅行商人的猪车。

请参考我上传的视觉参考图：

- 猪车位于画面中央

- 旅行商人位于猪车附近

- 猪车和商人是画面的视觉中心

- 左右两侧是草地、树林、花、石头等自然环境

- 持续有像素雨落下

- 整体像一款完整的 2D 复古像素 RPG 场景

不要出现玩家角色。

不要出现 Jinn。

Jinn 只会在未来的故事结尾出现，现在不要添加。

--------------------------------------------------

HUD

--------------------------------------------------

屏幕左上角固定显示 10 颗空心。

类似复古 RPG 中的好感度系统。

初始状态：

♡ ♡ ♡ ♡ ♡ ♡ ♡ ♡ ♡ ♡

目前不需要实现心形填充逻辑，但请预留状态和组件结构，方便后续开发。

--------------------------------------------------

TRAVELING MERCHANT DIALOGUE

--------------------------------------------------

主场景加载后，旅行商人出现一个像素游戏对话框。

对话框位于屏幕底部。

旅行商人的角色语气：

- 比较潇洒

- 有一点神秘

- 但也有一点像好奇的小女孩

- 不要成熟严肃

- 不要话太多

对话流程：

旅行商人：

“哦？新客人？”

“欢迎你，{用户输入的名字}。”

“不过……今天好像出了点小问题。”

“我的车上，混进了一些不属于我的东西。”

“挺奇怪的，对吧？”

然后：

“这个给你。”

显示获得物品 UI：

🔍

你得到了一把放大镜！

然后继续：

“拿着它找找看吧。”

“说不定，这里面刚好有你想找的东西。”

对话结束后，用户可以自由探索猪车。

==================================================

MAIN HUB INTERACTION

==================================================

猪车上有多个物品。

其中包括：

主线物品：

1. 一张旧照片

2. 一个珍贵的陶瓷展品

3. 一个望远镜

干扰项 / 彩蛋物品：

- 泳镜

- 花

- 热带植物

- 旧书

- 奇怪的小物品

这些物品不要像任务按钮一样排列。

它们应该自然混在旅行商人的货物里。

--------------------------------------------------

HOVER

--------------------------------------------------

鼠标移动到可互动的物品时：

- 鼠标可以变成像素风放大镜

- 或物品出现非常轻微的像素闪光

不要使用现代网页 hover 效果。

不要出现现代 tooltip。

--------------------------------------------------

CLICK

--------------------------------------------------

点击任意物品：

该物品以 1:1 的视觉效果放大显示。

可以通过简单的 zoom animation 完成。

目前第一版不需要制作复杂动画。

只需要实现点击 → 放大 → 返回主场景。

--------------------------------------------------

PHOTO

--------------------------------------------------

旧照片是目前唯一真正可以进入故事的主线物品。

点击后：

放大照片。

照片内容是：

- 内蒙古草原

- 蒙古包

- 一个小女孩

目前只需要做一个简单的 placeholder Story 页面。

例如：

“我的故事，从这里开始。”

之后可以返回主场景。

后续我会继续开发完整的 Story 01。

--------------------------------------------------

VASE

--------------------------------------------------

陶瓷展品目前尚未解锁。

点击后放大。

显示：

？

或者：

“似乎还看不出什么。”

不要进入 Story。

--------------------------------------------------

TELESCOPE

--------------------------------------------------

望远镜目前尚未解锁。

点击后放大。

显示：

？

或者：

“似乎还缺少一些线索。”

不要进入 Story。

--------------------------------------------------

EASTER EGG ITEMS

--------------------------------------------------

点击泳镜、花、热带植物等物品后：

物品放大。

然后出现一句简短的像素游戏风格文字。

这些文字用于透露 Jinn 的兴趣，但不进入主线故事。

例如：

泳镜：

“这个泳镜看起来是属于 Jinn 的。”

“她是游泳健将吗？”

请为其他彩蛋物品设计类似的简短描述。

==================================================

TECHNICAL REQUIREMENTS

==================================================

请使用一个结构清晰、方便后续继续开发的前端项目。

要求：

- React

- TypeScript

- 组件化结构

- 清晰的 state management

- 将 Scene 设计为独立组件

- 将 Dialogue System 设计成可以方便添加新对话的组件

- 将 Interactive Objects 设计成可配置的数据结构

- Heart System 设计成独立组件

- 后续方便增加：

  - Story 01

  - Story 02

  - Story 03

  - Secret Notes

  - Heart progression

  - Final Ending

  - Stardrop

  - Butterfly animation

  - Balloon animation

重要：

目前不要试图一次完成整个网站。

这只是 Phase 1 Prototype。

优先保证：

1. Scene Flow 正确

2. 页面之间切换自然

3. 像素游戏感正确

4. 主场景构图正确

5. 交互结构方便后续扩展

不要为了增加功能而加入任何我没有要求的现代网页元素。
